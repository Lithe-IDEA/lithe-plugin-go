0.0.1 是按插件契约 v0 重新发布的首个版本。

功能：
- gopls 代码智能：补全、跳转定义、悬停、诊断和格式化。
- 声明式构建系统 Go Modules：用 `go list -json ./...` 读取模块和包，`go.mod`、`go.sum`、`go.work` 变化后重新读取。
- 构建窗口里的 Build、Vet 任务，编译诊断显示为问题。
- 每个 `main` 包都有「运行 <包名>」入口，执行 `go run <导入路径>`。
- 测试整个模块、单个包或单个测试。
- 用 `go list -m -json all` 列出模块依赖。
- 插件设置 Go executable，以及 gopls 的 Staticcheck analyses、Format with gofumpt、Parameter placeholders in completion、Hover documentation 四项设置。
- 构建选项 Build Tags（`-tags`）和 Race Detector（`-race`）。

权限：`languageServer.launch`、`process.build`。

兼容性：
- 只能装进新版 Lithe 桌面端（`desktop-v*` 预发布），旧版 macOS Lithe 无法安装。
- 本版本是预发布，Lithe Store 的自动追踪会跳过它。
