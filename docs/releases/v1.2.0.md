1.2.0 给「运行/调试配置」里的 Go 构建和 Go 测试换上各自的图标：Go 地鼠加构建标记或测试标记，浅色和深色外观各有一套。这个版本以预发布版本发布。

功能：
- Go 构建的图标是 Go 地鼠，右上角加构建用的锤子；Go 测试的图标是 Go 地鼠，右上角加红绿两色的测试标记。深色外观换用对应的深色配色。
- 图标显示在「+」菜单、对话框左侧的配置树和标题栏的运行配置列表里，替换原来按执行类别显示的通用图标。

已知限制：
- 显示这两个图标需要支持插件包图标的桌面端（1lck/Lithe-IDEA#2169）。桌面端 0.8.6 也能安装这个版本，两种配置照常使用，图标仍是通用图标。

验证：
- 在 macOS 上用包含 1lck/Lithe-IDEA#2169 的桌面端跑宿主端到端测试：两种配置都读到了包里的浅色和深色图标，运行结果和保存的配置与 1.1.0 相同，插件安装目录不被写入。
- 用包里的四个图标文件在同一个桌面端的无头界面里截图检查「+」菜单，浅色和深色外观下构建和测试图标都按各自配色画出。
- 还没有在 Lithe 里手工验收，状态见 `docs/feature-matrix.md`。

权限：不变。

兼容性：
- 清单只给两种配置的图标加了深色文件，桌面端 0.8.6 可以安装。显示图标需要 1lck/Lithe-IDEA#2169。
- 图标改编自 JetBrains IntelliJ Community 的图标（Apache-2.0），出处和改动说明见包里的 `icons/NOTICE`。
