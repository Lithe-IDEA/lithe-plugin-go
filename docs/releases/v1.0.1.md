1.0.1 加入 Windows 安装包，同时支持 Windows ARM64 和 x64。插件行为和 1.0.0 相同，macOS 用户不需要更新。

功能：
- Windows：Release 新增 `go-support-1.0.1-windows.zip`，与 darwin 包字节相同。插件只声明 Lithe 怎样启动你电脑上的 go、gopls 和 dlv：Windows 上从 GOROOT 解析 `bin\go.exe`，在 `C:\Program Files\Go`、Scoop 等位置找到 Go；`gopls` 和 `dlv` 按 PATHEXT 找到 `gopls.exe`、`dlv.exe`。在插件详情里安装 gopls 和 dlv 同样可用，装进 Lithe 管理的目录或 Go 的默认位置（`go env GOBIN`，为空时 GOPATH 列表第一项下的 `bin`）。

验证：
- CI 在 Windows x64、Windows ARM64 和 macOS 上用真实的 go、gopls、dlv 运行清单里的命令（`scripts/test.mjs`）：版本探测、模型和依赖、构建、vet、过滤后的测试、`go env` 目录、gopls 和 dlv 的托管安装、gopls 的校验参数和 `dlv dap` 的端点公告。Windows 上测的是解压到带空格路径的 windows 包。
- 这些是命令层面的自动化测试，还没有在 Windows 版 Lithe 里手工验收，状态见 `docs/feature-matrix.md`。

权限：不变。

兼容性：
- 宿主要求与 1.0.0 相同（1lck/Lithe-IDEA#1954、#1964、#1971、#1975）。
- 只能装进新版 Lithe 桌面端（`desktop-v*` 预发布）。
- 本版本是预发布，Lithe Store 的自动追踪会跳过它。
