0.1.0 加入 Delve 调试和新建 Go 项目。

功能：
- 调试：「调试」窗口里的 Go (Delve) 适配器用你电脑上的 `dlv dap` 调试当前文件所在的包，支持断点、单步、调用栈、变量和表达式求值；程序结束后会话自动结束，程序输出留在调试控制台。
- 新建项目：「新建项目」对话框里的 Go 生成 `go.mod` 和 `.gitignore`，可选生成示例 `main.go`；可以选择 GOROOT（从电脑上找到的 Go 里选，默认最新的一个，创建后项目固定使用它），填写模块路径（默认是小写的项目名）和 Go 版本（高级，默认是所选 GOROOT 的版本）。不运行 `go mod init`，创建项目不需要联网；没有找到 Go 时 GOROOT 留空，Go 版本需要手动填写。
- 工具链：插件声明 `go` 工具，Lithe 在 Homebrew、`/usr/local/go`、`~/sdk/go*` 等位置找到 Go 并读出版本，列在「构建、执行、部署 › 工具链」里。没有设置 Go executable 时，构建、检查、测试和运行使用项目固定的 Go，没有固定时依次使用全局默认、`GOROOT`、`PATH` 里的 `go` 和找到的最新安装。
- 插件设置的中文名称和说明（`l10n/zh-Hans.json`）。

权限：新增 `debug.launch`（启动 Delve）和 `project.generate`（新建项目），原有 `languageServer.launch`、`process.build` 不变。

依赖的程序：调试需要 `PATH` 里的 `dlv`（`go install github.com/go-delve/delve/cmd/dlv@latest`）；不调试可以不装。

兼容性：
- 需要固定了 Rust Core 6477e9a 或更新版本、并能启动 `tcpAnnounced` 调试适配器的桌面端（1lck/Lithe-IDEA#1954、1lck/Lithe-IDEA#1964）。更早的桌面端会拒绝安装本版本：它的 Core 不认识调试配置里的 `target.directory` 绑定（Core a58e07e 起支持），也不接受以子命令开头的版本探针 `go version`（Core 6477e9a 起支持）。
- 新建项目的字段名称和调试适配器名称目前只有英文：插件语言文件还不能翻译这两类文字。
- 只能装进新版 Lithe 桌面端（`desktop-v*` 预发布），旧版 macOS Lithe 无法安装。
- 本版本是预发布，Lithe Store 的自动追踪会跳过它。
