1.3.0 给 Go 的两个设置页加上插件自己画的预览，改设置时直接看到效果。这个版本以预发布版本发布。

功能：
- 「设置 › 语言 › Go」顶部有四张预览卡片：悬停文档显示多少内容、补全是否填参数占位符、gofumpt 格式化前后的代码、Staticcheck 多查出的问题。
- 「构建工具 › Go」页画出 Lithe 查找 go 程序的顺序；设置了 go 路径时只有这一步“使用中”。
- 改了还没应用的选项会先在预览里显示，并标出“含未应用的修改”。预览跟随界面语言和浅色、深色外观。

已知限制：
- 需要支持插件视图的桌面端（1lck/Lithe-IDEA#2183）。更早的桌面端不认识 `settingRegions`，无法安装这个版本，Store 继续提供 1.1.0。
- Windows 上代码的字距比 Lithe 自己画的略宽：预览按 SF Mono 的字宽排版代码，选区和波浪线才能对准字符。

验证：
- 在 macOS 上用 1lck/Lithe-IDEA#2183 的桌面端跑宿主端到端测试：后端由宿主启动，两个预览在中英文下都画出、通过 Core 校验，草稿会改变预览，插件安装目录不被写入；原有的构建、调试、运行配置和新建项目测试也都通过。
- 用宿主无头界面截图检查了最小和较宽窗口、中英文、浅色和深色外观。
- Windows 包的后端只在 CI 里构建，还没有在 Windows 版 Lithe 里打开过；状态见 `docs/feature-matrix.md`。

权限：新增 `backend.launch`（启动包里的预览后端）和 `ui.contribute`（在设置页显示预览）。

兼容性：
- 发布包按平台分开：`-darwin.zip`（Apple Silicon 和 Intel 通用）、`-windows-x64.zip`、`-windows-arm64.zip`。原来的 `-windows.zip` 不再提供。
- 后端用到的第三方 crate 和许可证见包里的 `THIRD_PARTY_LICENSES.txt`。
