1.0.0 加入 Delve 调试、新建 Go 项目、GOROOT 选择，以及在插件详情里安装 gopls 和 dlv。本版本要求更新的 Lithe 桌面端，能装 0.0.1 的桌面端装不了它，所以升主版本号。

升级说明：
- 不兼容的变化只有一项：本版本需要更新的桌面端（要求见下面“兼容性”第一条）。能装 0.0.1 的桌面端都早于这些改动，会拒绝安装或更新到本版本。
- 需要做的：先把 Lithe 桌面端更新到包含 1lck/Lithe-IDEA#1975（固定了 Lithe-core-rust#55 的 Rust Core）的版本，再安装本版本。
- 设置不需要迁移：Go executable 和四项 gopls 设置的键和取值都没变，0.0.1 的构建任务、运行入口、测试和依赖列表全部保留。

功能：
- 调试：「调试」窗口里的 Go (Delve) 适配器用你电脑上的 `dlv dap` 调试当前文件所在的包，支持断点、单步、调用栈、变量和表达式求值；程序结束后会话自动结束，程序输出留在调试控制台。Delve 在当前文件所在的包目录构建和运行程序，`os.ReadFile("examples/input.txt")` 这样的相对路径从包目录算起；打开的文件夹根目录不需要 `go.mod`，可以并排放多个模块，模块里的子包（如 `cmd/tool`）和没有 `go.mod` 的目录（按 `GO111MODULE=auto` 构建目录里的全部文件）也能调试。
- 新建项目：「新建项目」对话框里的 Go 生成 `go.mod` 和 `.gitignore`，可选生成示例 `main.go`；可以选择 GOROOT（从电脑上找到的 Go 里选，默认最新的一个，创建后项目固定使用它），填写模块路径（默认是小写的项目名）和 Go 版本（高级，默认是所选 GOROOT 的版本）。不运行 `go mod init`，创建项目不需要联网；没有找到 Go 时 GOROOT 留空，Go 版本需要手动填写。
- 工具链：插件声明 `go` 工具，Lithe 在 Homebrew、`/usr/local/go`、`~/sdk/go*` 等位置找到 Go 并读出版本，列在「构建、执行、部署 › 工具链」里。没有设置 Go executable 时，构建、检查、测试和运行使用项目固定的 Go，没有固定时依次使用全局默认、`GOROOT`、`PATH` 里的 `go` 和找到的最新安装。
- 安装 gopls 和 dlv：缺少时，插件详情「功能」页的能力卡片显示“未找到 gopls”或“未找到 dlv”和安装按钮。可以装进 Lithe 管理的目录（卸载插件时一起删除），也可以装进 Go 的默认位置（`go env GOBIN`，为空时 `$(go env GOPATH)/bin`）；安装用「工具链」选出的 Go 运行 `go install <包>@latest`，需要联网。装好的位置会被记下，不需要再改 `PATH`。
- 插件设置的中文名称和说明（`l10n/zh-Hans.json`）。

权限：新增 `debug.launch`（启动 Delve）、`project.generate`（新建项目）和 `commands.install`（安装 gopls、dlv，每次安装前都会确认），原有 `languageServer.launch`、`process.build` 不变。

依赖的程序：代码智能需要 `gopls`，调试需要 `dlv`，都可以在插件详情里安装，也可以自己用 `go install` 装进 `PATH`；不调试可以不装 dlv。

兼容性：
- 需要固定了包含 Lithe-core-rust#55 的 Rust Core、能启动 `tcpAnnounced` 调试适配器并支持 `commandInstallers` 的桌面端（1lck/Lithe-IDEA#1954、1lck/Lithe-IDEA#1964、1lck/Lithe-IDEA#1971、1lck/Lithe-IDEA#1975）。更早的桌面端会拒绝安装本版本：它的 Core 不认识调试配置里的 `targetBindings.adapterArguments`，也不允许 `targetBindings.cwd` 绑到 `target.directory`（Lithe-core-rust#55 起支持），不认识调试配置里的 `target.directory` 绑定（Core a58e07e 起支持），不接受以子命令开头的版本探针 `go version`（Core 6477e9a 起支持），也不提供 `commandInstallers` 能力（Core c550c2b 起支持）。
- 新建项目的字段名称和调试适配器名称目前只有英文：插件语言文件还不能翻译这两类文字。
- 只能装进新版 Lithe 桌面端（`desktop-v*` 预发布），旧版 macOS Lithe 无法安装。
- 本版本是预发布，Lithe Store 的自动追踪会跳过它。
